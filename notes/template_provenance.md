# ICLR 2027 模板来源与使用

核实日期：2026-09-09。

正式来源为 [ICLR 2027 Author Guidelines](https://iclr.cc/Conferences/2027/AuthorGuidelines) 中直接给出的 [style-files ZIP](https://media.iclr.cc/Conferences/ICLR2027/iclr-2027-style-files.zip)。同时核对 [ICLR/Master-Template 的 iclr2027 目录](https://github.com/ICLR/Master-Template/tree/master/iclr2027)，读取时 master commit 为 `46ed6f4c6cef5b175dde23639e77d44c3463b230`。官网 ZIP 与 GitHub ZIP 中的所有模板文件逐字节一致。

原始 ZIP 保存在 `vendor/iclr-2027-style-files.zip` 与 `vendor/iclr2027.zip`；解压文件在 `vendor/iclr2027/`，保持原样。网页副本在 `sources/iclr2027_*.html`，commit 元信息在 `sources/iclr_template_commit.json`。这是真实 2027 模板，不是由 2026 模板修改年份。

正文使用 `iclr2027_conference.sty` 与 `iclr2027_conference.bst`，未启用 `iclrfinalcopy`，保留匿名作者与审稿行号。没有修改字号、页边距或官方 style。

官网 author guidelines 的主要要求：初次提交主文最多 9 页；discussion/rebuttal 和 camera-ready 上限 10 页；references 与 bibliography 不计入，appendix 放在 bibliography 之后。AI use statement 是必需段落，不计入主文页数；reproducibility statement 为推荐项。草稿已加入这两部分，AI 声明中的人工核实尚需作者在最终提交前完成。

官网列出的摘要截止为 **2026-09-18 23:59 AoE**，全文截止为 **2026-09-25 23:59 AoE**，分别对应北京时间 **2026-09-19 19:59** 和 **2026-09-26 19:59**。本地写作不包含 OpenReview 注册、作者名单确认或提交操作。

AI 使用政策原文见 [AIPolicyForAuthors](https://iclr.cc/Conferences/2027/AIPolicyForAuthors)。正文只描述本次实际发生的 AI 辅助，不预先声称作者已经完成全部人工审查。
