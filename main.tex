\begin{abstract}
Data-centric self-improvement requires turning evidence about a model's limitations into useful training experience. We study tool-using agents when target interaction traces are available but the target environment implementation is not. We present \method{}, which starts from an empty task-environment bank and maintains a persistent library of executable training programs. A fixed Planner combines source-linked trajectory analysis, measured task-linked requirement groups, versioned online rewards and maintained research experience to create, revise, retain or pause environments. Each program jointly defines task sampling, interaction and verification; bounded implementation checks precede fresh online RL without a separate student probe. Updated target behavior informs subsequent research. In preliminary single-seed Qwen3-4B studies, development-selected checkpoints score 42.08\% on BFCL multi-turn test versus a matched 25.42\% base, and 52.22\% on native-tool-calling ACEBench-Agent versus 41.11\%. The latter estimate has substantial small-test-set uncertainty. On $\tau^2$, the selected checkpoint reaches 39.33\% test success but the last declines to 34.05\%. These protocol-qualified trajectories demonstrate useful checkpoints alongside regressions; controlled comparisons are still needed to establish the contribution of persistent environment evolution.
\end{abstract}
